## 1. JDBC 개요

> JDBC(Java Database Connectivity)는 Java를 이용하여 Database에 있는 값을 활용하기 위한 API
> 

- JDBC Driver는 Java 응용 프로그램이 데이터베이스와 상호 작용할 수 있도록 하는 소프트웨어 구성 요소(class & interface)

## 2. JDBC 활용 전체 과정

### (JDBC)Driver Loading

- 프로그램에서 딱 1번만 수행하면 된다.

### 데이터베이스 연결

- 연결 성공시 연결 성공의 증표로 객체(Connection Class)가 생성
- 연결을 위해서는 3가지 정보 필요
- 어떤 DB에 접속하는지에 대한 정보(문자열) => JDBC URL(정해진 형식 존재, jdbc:dbms_name)
- ID / PW 필요

### Statement 생성 => SQL 작성

### Query 실행

- `executeUpdate()`
    - SQL 구문이 insert, update, delete 계열일 때 사용
    - 리턴 값은 SQL 에 의해 영향을 받은 행의 수
- `executeQuery()`
    - SQL 구문이 select 일 때 사용
    - 리턴 값은 ResultSet

### 결과 처리

- `beforeFirst() :` 커서를 첫 번째 행 바로 앞에 이동합니다.
- `afterlast()`: 커서를 마지막 행 바로 뒤로 이동합니다.
- `first()` : 커서를 첫번째 행으로 이동합니다.
- `last()` : 커서를 마지막 행으로 이동합니다.
- `absolute(int now`): 커서를 지정된 행으로 이동합니다.
- `relative(int row)`: 현재 위치에서 주어진 수의 행 앞으로 또는 뒤로 커서를 이동합니다.
- `previous()`: 커서를 이전 행으로 이동합니다. 이전 행이 결과 집합을 벗어나면 false를 반환합니다.
- `next()`: 커서를 다음 행으로 이동합니다.
- `getRow()`: 커서가 가리키는 행 번호를 반환합니다.

### 리소스 해제

- 지금 사용된 자원은 Connection, PreparedStatement, ResultSet
- `rs.close()` → `pstmt.close()`  → `conn.close()`

```java
import java.sql.*;

public class FirstConnect {
    public static void main(String[] args) {
        try {
            // 1. driver loading
            Class.forName("oracle.jdbc.driver.OracleDriver");
            System.out.println("드라이버 로딩 성공");

            // 2. db connection
            String JDBC_URL = "jdbc:oracle:thin:@localhost:1521:xe";
            String ID = "";
            String PW = "";
            Connection conn = DriverManager.getConnection(JDBC_URL, ID, PW);
            System.out.println("DB 연결 성공");

            // 3. Statement 생성(sql 작성)
                // Statement 의 종류
                // 1. 일반 Statement => 단순, 기능상 약간 부족(잘 안쓴다)
                // 2. PreparedStatement => 코드 작성 편함, 효율이 좋다, SQL Injection 방지 (가장 많이 사용)
                // 3. CallableStatement => Stored Procedure 호출하기 위해 사용
            String sql = "SELECT BTITLE FROM BOOK WHERE BISBN = '979-11-5664-149-0'";
            PreparedStatement pstmt = conn.prepareStatement(sql);

            // 4. Query 실행
            ResultSet rs = pstmt.executeQuery();

            // 5. 결과처리
           if (rs.next()) {
                // 결과가 존재하면
                System.out.println(rs.getString("BTITLE"));
           } else {
               System.out.println("검색 결과가 없습니다.");
           }
            rs.close();
           pstmt.close();
           conn.close();
        } catch (ClassNotFoundException e) {
            System.out.println("Driver not found: " + e.getMessage());
        } catch (SQLException e) {
            System.out.println("Connection error: "+ e.getMessage());
        }
    }
}
```

```java
public class SecondConnect {
    public static void main(String[] args) {
        // 책 제목에 대한 키워드를 입력받아서 책 제목에 대한 해당 키워드를 포함하고 있는
        // 책에 제목에 해당 키워를 포함하고 있는 책을 검색한 다음
        // 해당 책에 대한 책 제목, 저자, 가격 정보를 출력
        Connection con = null;
        PreparedStatement pstmt = null;
        ResultSet rs = null;

        String JDBC_URL = "jdbc:oracle:thin:@localhost:1521:xe";
        String ID = "";
        String PW = "";
        try {
            Class.forName("oracle.jdbc.driver.OracleDriver");
            System.out.println("Oracle JDBC Driver Loaded");
            con = DriverManager.getConnection(JDBC_URL, ID, PW);
            System.out.println("Oracle JDBC Connection Created");
            Scanner sc = new Scanner(System.in);
            System.out.println("검색어를 입력하세요 => ");
            String keyword = sc.nextLine();

            // IN Parameter 를 이용해서 SQL query 를 작성하는게 좋다
            String sql = "select btitle, bauthor, bprice ";
            sql += "from book where btitle like ?";
            pstmt = con.prepareStatement(sql);
            pstmt.setString(1, "%" + keyword + "%");
            rs = pstmt.executeQuery();

            while (rs.next()) {
                String tmp = "";
                tmp += "title: " + rs.getString("btitle") + " ";
                tmp += "author: " + rs.getString("bauthor") + " ";
                tmp += "price: " + rs.getString("bprice") + " ";
                System.out.println(tmp);
            }

        } catch (ClassNotFoundException e) {
            System.out.println("Driver not found: " + e.getMessage());
        } catch (SQLException e) {
            System.out.println("Connection error: "+ e.getMessage());
        } finally {
            try {
                rs.close();
                pstmt.close();
                if (con != null) {
                    con.close();
                }
                System.out.println("Connection closed.");
            } catch (SQLException e) {
                System.out.println("Connection close fail: " + e.getMessage());
            }
        }
    }
}
```

## 3. JDBC Transaction

- 기본적으로 autoCommit mode 로 Connection 생성
- transaction을 설정하려면 `conn.setAutoCommit(false)`
- 명시적으로 `conn.commit()` 혹은 `conn.rollback()`이 호출되면 transaction 종료
- 만약 해당 구문이 나오지 않고 connection이 정상종료되면 conn.commit() 으로 간주

```java
import java.sql.*;

public class TransactionTest {
    public static void main(String[] args) {
        Connection conn = null;
        PreparedStatement pstmt = null;
        String JDBC_URL = "jdbc:oracle:thin:@localhost:1521:xe";
        String ID = "";
        String PW = "";
        try {
            Class.forName("oracle.jdbc.driver.OracleDriver");

            conn = DriverManager.getConnection(JDBC_URL, ID, PW);
            // 기본적으로 autoCommit mode 로 Connection 생성
            // 만약 transaction을 설정하려면
            conn.setAutoCommit(false); // transaction 시작
            // 명시적으로 conn.commit() 혹은 conn.rollback() 이 호출되면 transaction 종료
            // 추가적으로 만약 해당 구문이 나오지 않고 connection 정상 종료되면 conn.commit() 으로 간주

            String sql = "insert into membertbl values(?, ?)";
            pstmt = conn.prepareStatement(sql);
            pstmt.setString(1, "2");
            pstmt.setString(2, "심사임당");
            int result = pstmt.executeUpdate(); // 리턴값은 영향 받은 row 의 수

            if (result == 1) {
                System.out.println("insert success");
            } else {
                System.out.println("insert fail");
            }
            conn.commit();

        } catch(SQLException e) {
            System.out.println("SQLException: " + e.getMessage());
        } catch (ClassNotFoundException e) {
            System.out.println("ClassNotFoundException: " + e.getMessage());
        } finally {
            try {
                pstmt.close();
                conn.close();
            } catch (SQLException e) {
                System.out.println("SQLException: " + e.getMessage());
            }
        }
    
}
```
