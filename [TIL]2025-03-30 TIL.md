## 프로젝트

- 비정상 주문 시나리오에 따라 주문 클라이언트 메시지 전송 코드 리팩토링
- 단일 클라이언트 → 다수 주문 전송 방식 구현 완료

### 1. 실행 시 시나리오 선택 방식 확장

```c
void run_user() {
    int choice;
    while (1) {
        printf("=====================================\n");
        printf("|                                   |\n");
        printf("|           유저 프로그램           |\n");
        printf("|                                   |\n");
        printf("=====================================\n");
        printf("|          메           뉴          |\n");
        printf("-------------------------------------\n");
        printf("|  1. 정상 주문                     |\n");
        printf("-------------------------------------\n");
        printf("|  2. 비정상 주문[1]                |\n");
        printf("-------------------------------------\n");
        printf("|  3. 비정상 주문[2]                |\n");
        printf("-------------------------------------\n");
        printf("|  4. 비정상 주문[3]                |\n");
        printf("-------------------------------------\n");
        printf("|  5. 종료                          |\n");
        printf("-------------------------------------\n");
        printf(">> 메뉴를 선택하세요 : ");
        scanf("%d", &choice);
        system("cls");
        switch (choice) {
        case 1: run_normal_order(); break;
        case 2: run_abnormal_order_1(); break;
        case 3: run_abnormal_order_2(); break;
        case 4: run_abnormal_order_3(); break;
        case 5: return;
        default: printf("올바른 메뉴를 선택하세요\n"); break;
        }
        system("cls");
    }
}

```

### 2. 콘솔 창 안 뜨게 하기 (Windows GUI 프로젝트)

- 프로젝트 → 속성 → 링커 → 시스템 → **서브시스템: Windows** 설정
- 진입점은 `WinMain()` 사용 필요
- 또는 링커 → 고급 → 진입점 수동 설정: `mainCRTStartup`
