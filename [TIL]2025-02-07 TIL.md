## 2. String class

- string class는 assign으로도String 객체를 생성 가능
- `“ ”` 을 이용해서 String 객체를 생성하면 힙 영역에 String Pool에 들어간다
- `new` 키워드를 사용해서 생성하면 일반 힙 영역에 저장
- String 인스턴스는 immutable(불변)

```java
public class StringClass {
    public static void main(String[] args) {
        String str1 = "홍길동";
        String str2 = "홍길동";
        String str3 = new String("홍길동");

        System.out.println(str1 == str2); // true
        System.out.println(str1== str3); // false
        System.out.println(str2.equals(str3)); // true
    }
}
```

## 3. Array

- 배열은 같은 type의 data를 여러 개 저장할 수 있는 자료구조
- 배열은 객체이다
- 배열을 만들기 위해서 new keyword를 사용
- 사이즈가 고정되어 있다

## 4. ArrayList

- 배열과 유사
- Instance만 저장 가능()
- primitive type은 저장 불가능하지만 `wrapper class`를 제공해주기 때문에 저장 가능

### 배열과 차이점

- 크기가 유동적이다
- 다른 data type을 저장 가능(일반적으로 generic를 사용하여 같은 data type만 저장)

```java
import java.util.ArrayList;

public class ArrayListTest {
    public static void main(String[] args) {
        // 배열
        String[] strArr = new String[5];

        // ArrayList
        ArrayList list = new ArrayList();

        // 객체이기 때문에 당연히 method를 통해서 이 객체를 제어
        list.add("홍길동");
        list.add("안녕안녕!");
        list.add(100); // 원래는 안되는데 autoboxing이 발생해서 Interger 객체가 만들어진다
        // list.add(new Integer(100))
        list.add(true);
        for (Object obj : list) {
            System.out.println(obj);
        }
        
        ArrayList<String> genericList = new ArrayList<String>();
        genericList.add("홍길동");
        genericList.add("최길동");
//        genericList.add(100); error
        for (String str : genericList) {
            System.out.println(str);
        }

    }
}
```

## 7. Exception

- JVM이 Exception class를 이용해 예외 상황에 맞는 인스턴스를 생성
- Exception 객체가 처리되지 않으면 program은 비정상 종료
- Java에서 Exception을 처리하는 유일한 방법은 `try ~ catch` 구문

```java
ublic class ExceptionTest {
    public static void main(String[] args) {
        System.out.println("Exception을 발생시킨다");
        try {
//            int a = 1 / 0;
            Object obj = null;
            System.out.println(obj.toString());
        } catch (NullPointerException e) {
            System.out.println(e.getMessage());
        }
        finally {
            System.out.println("이 코드는 무조건 실행");
        }
    }
}
```
